# 吃药服务

在线地址：https://newyik.github.io/medicine-service/

## 用药记录
支持自定义药物与彩色图标、多种用药类型、月历回看；今天与昨天默认展开，更早记录按月份归档。适配手机、平板和电脑。
## 看病记录
右上角「看病记录」进入 `#visits`。支持医院、时间、科室、医生、就诊原因、诊疗摘要、自付费用、复诊日期与备注，以及关键词筛选、详情展开与修改。
医院查询使用 Nominatim / OpenStreetMap，手动点击查询，限制日本，缓存查询结果；不可用时可手动填写。查询只使用独立的医院名／地区输入，不发送就诊内容。
备份版本 3 同时包含 `visits`，兼容导入旧版用药备份。部署新环境前应执行 `migrations/preserve-visits.sql`，防止仍打开旧版页面的设备写回时丢失看病记录。该 SQL 不更改用户或药物记录，只为旧客户端保留它不知道的新字段。
验证：`node --test tests/visits.test.mjs`。

## 双登录方式
保留 GitHub 登录，新增邮箱＋密码登录。已有 GitHub 账号登录后，可以在「邮箱登录设置」中通过 `auth.updateUser({password})` 为当前账号设置邮箱密码，账号 ID 与原有记录不变。不更改邮箱、不调用注册接口、不自动创建第二个账号；忘记密码可用原 GitHub 登录后重设。邮箱验证配置保持原样。
开发预览使用独立模拟数据，不连接真实账号。生产文件不包含模拟数据或演示账号。
验证全部检查：`node --test tests/*.test.mjs`。

## 预约处理
页面打开时显示到点／过时待确认提醒。用户确认完成后才加入就诊记录；支持改期、取消和恢复。暂不包含手机后台推送。
